# dvre_workflow_composer

[![Github Actions Status](https://github.com/ThomasSchilder/dvre-workflow-composer/workflows/Build/badge.svg)](https://github.com/ThomasSchilder/dvre-workflow-composer/actions/workflows/build.yml)

A JupyterLab extension.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install dvre_workflow_composer
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall dvre_workflow_composer
```
